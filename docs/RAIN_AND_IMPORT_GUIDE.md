# 潮汐沙岸：雨幕与本地资源导入指南

## 1. 设计边界

雨幕与资源导入都是可选系统。页面首次打开时雨幕关闭、导入槽为空，因此原有沙滩物体、镜头、
光照、潮汐和默认 Draw Call 不发生变化。用户主动操作后才产生额外渲染与内存成本。

## 2. 立体雨幕

`RainSystem` 使用一个 `THREE.LineSegments` 绘制整片雨幕。每滴雨预留 6 个顶点：前 2 个组成
雨丝，后 4 个组成两束短促飞溅。位置缓冲设置为 `DynamicDrawUsage`，每帧只更新同一块
`Float32Array`：

- 高画质：1100 滴雨；
- 低画质与移动端：520 滴雨；
- 开启成本：1 个 Draw Call，0 个三角形；
- 关闭成本：不参与渲染，也不更新顶点；
- 雨线随相机水平位置循环，飞行或漫步时不会离开雨区；
- 长度、速度和明暗有确定性变化，形成近远层次；
- 风向同时影响下落位置和线段倾角；
- 雨丝下端接近地表后，取 `max(水面高度, terrainHeight)` 作为实际落点；
- 接触后两束方向分散的水花短暂上扬，结束时顶点折叠，不增加渲染对象；
- Water 镜像渲染会临时隐藏雨幕，避免重复绘制和错误倒影。

雨幕默认关闭时只保存画质参数，不创建数组、Geometry、Material 或 LineSegments。首次开启才分配
当前画质资源；关闭后保留同一对象以便快速重开。若关闭状态切换画质，则释放旧规格资源并把新
规格延迟到下一次开启；开启状态切换画质会立即替换资源并保持雨幕运行。所有废弃几何和材质均
显式释放，Water 反射排除登记随雨线对象同步更新。精确字节与状态说明见
[雨幕资源延迟创建与释放指南](./RAIN_RESOURCE_LIFECYCLE_GUIDE.md)。

## 3. 本地贴图导入

设置面板选择“导入贴图”后，可读取 PNG、JPEG、WebP 或 AVIF，文件上限 15 MB。贴图通过
`createImageBitmap()` 解码并转换为 `CanvasTexture`，使用 sRGB 色彩空间和受设备限制的各向异性。

贴图不会替换沙地或水面材质，而是生成独立展示板。这能避免任意宽高比和未知纹理破坏原场景，
同时让导入结果立即可见。展示板按图片比例限制在合理尺寸，并自动朝向默认观察区域。

## 4. 本地模型导入

支持 GLB，以及所有缓冲区和图片均以内嵌 data URI 保存的 glTF，文件上限 30 MB。外接 `.bin`
或外部图片的多文件 glTF 会被拒绝，建议在建模软件中导出单一 GLB。

导入流程：

1. 用户选择文件后才动态加载 `GLTFLoader`，不占用首屏解析成本；
2. 解析模型并统计网格与三角形；
3. 超过 500,000 个三角形时拒绝加入场景；
4. 忽略模型自带灯光和相机，避免改变沙滩整体照明与视角；
5. 保留模型材质，接入当前阴影设置；
6. 按最大包围盒尺寸缩放到约 4 米并贴合沙地；
7. 存在动画时自动播放第一段动画并显示动画控制；
8. 新导入会替换旧导入，避免资源无限累积。

当前未集成 Draco、KTX2 或 Meshopt 外部解码器；使用这些压缩扩展的 GLB 需要后续配置对应解码器。

## 5. 导入资源场景布置

模型或贴图成功导入后，“场景布置”才会显示。所有变换都作用于导入资源的外层 `Group`，不会
改写 glTF 内部节点、骨骼和关键帧：

- 横向 X 范围为 -32 至 32；
- 纵深 Z 范围为 14 至 44，保持在可观察的沙滩区域；
- 每次移动后通过 `terrainHeight(x, z)` 重新计算 Y，模型底部始终贴合地形；
- 水平旋转为导入默认朝向的 -180° 至 180° 偏移；
- 整体缩放范围为 0.5-2.00，不改变导入时的基础规格化比例；
- 重置会恢复 X = 2、Z = 25、旋转偏移 0°、缩放 1.00。

贴图展示板保留首次导入时朝向默认观察区的基础角度，用户调节的是相对偏移。变换状态进入
Debug State；替换资源后不会把上一份文件的位置误用到新文件。

## 6. 模型动画控制

每个动画模型只创建一个 `AnimationMixer`，glTF 中的每个 `AnimationClip` 通过菜单按索引选择：

- 导入后默认播放第一段动画；
- 切换片段时使用 0.35 秒 `crossFadeTo()` 平滑融合；
- 暂停将 Mixer 的 `timeScale` 设为 0，恢复时继续使用当前倍速；
- 动画倍速限制在 0.25-2.00，避免误操作产生极端时间步长；
- 重播只重置当前 `AnimationAction`，不重新解析模型；
- 静态模型和贴图不显示动画控件。

活动片段、播放状态、倍速和播放时间都进入 Debug State，便于自动回归确认暂停期间时间不前进。
移除或替换模型时先停止全部 Action，再调用 `uncacheRoot()` 清理 Mixer 对模型的绑定。

## 7. 隐私与释放

文件由浏览器的 `File` API 在本机读取，不会发送到服务器。导入管理器只保存当前一个资源。
点击“移除导入”、导入新资源或卸载页面时，会停止动画并去重释放：

- `BufferGeometry`；
- Material；
- Material 引用的 Texture；
- `ImageBitmap`；
- `AnimationMixer` 动作。

异步导入带操作序号。用户快速选择新文件时，较早完成的旧任务不会覆盖最新选择，其临时资源
会立即释放。

## 8. 自动验收

`npm run test:visual` 在桌面和移动端执行以下流程：

1. 验证雨幕默认关闭且没有创建数组、Geometry、Material、LineSegments 或反射排除项；
2. 从可见开关启用雨幕，检查延迟创建、密度、6 顶点结构和 1 个 Draw Call 增量；
3. 确认产生实际地形接触和活动飞溅，截取日光/月夜画面，再次关闭并复用同一资源；
4. 运行时生成 64 × 32 PNG 并导入；
5. 通过 UI 移动、旋转和缩放贴图，检查地形高度，再一键复位；
6. 运行时生成带两段旋转动画的内嵌 glTF 三角形模型并导入；
7. 移动并缩放动画模型，确认变换后 Mixer 时间仍继续推进；
8. 通过 UI 切换片段、暂停、改变倍速、恢复和重播，检查 Mixer 时间；
9. 分别截取桌面与移动端布置及动画控制面板；
10. 运行时封装静态网格为 GLB 二进制并再次导入，确认布置控件显示、动画控件隐藏；
11. 从 UI 移除资源，确认全部控件、状态与按钮复位；
12. 在关闭状态切换画质，确认旧雨线注销并释放，新规格仍保持延迟创建；
13. 继续执行原有潮汐、玩法、相机、布局和性能回归。
