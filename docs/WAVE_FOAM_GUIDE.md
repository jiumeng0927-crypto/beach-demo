# 海浪与岸线泡沫联动指南

0.40 更新：不仅主浪锋，破碎网纹和回退细节也统一到水面时间；泡沫网格直接复用沙地顶点行，加入冲刷周期与薄膜残留。最新实现和暂停像素测试见 [近岸细节学习记录](NEAR_SHORE_FINISH_040.md)。下文保留早期联动方案的学习过程。

## 1. 问题与目标

旧版 Water 使用自身累积的 `time` uniform，并受“海浪速度”控制；岸线泡沫却直接使用页面
总时间。改变速度后，水面会加速或减速，泡沫仍保持原节奏，近岸关系因此脱节。

本轮将 Water 时间设为唯一波浪相位源。场景物体、潮位和泡沫强度保持原样，只同步动态节奏。

## 2. 数据流

```text
海浪速度滑杆
  -> BeachEnvironment.waveSpeed
  -> Water.uniforms.time 累积
  -> BeachWorld.update(..., waterTime, waveSpeed)
  -> Foam.uWavePhase
```

`uTime` 仍负责泡沫内部的低速噪声漂移；`uWavePhase` 专门负责可观察的推进和回撤。
两者职责分离后，细碎纹理不会因为海浪速度变化而突然拉伸。

## 3. Shader 行为

泡沫主浪线在原有噪声岸线基础上增加正弦相位偏移，最大 UV 位移为 `0.065`。泡沫网格纵深
为 14 米，对应约 `0.91m` 的推进范围。入浪阶段主浪线略微展宽并增强，回撤阶段回流水线增强，
形成相反节奏，同时保留噪声断裂，避免整条岸线变成连续白带。

## 4. 性能

实现只增加一个 float uniform 和少量 GLSL 标量运算：

- 不增加几何体或材质；
- 不增加 Draw Call 或三角形；
- 不增加纹理或网络请求；
- 高低画质使用同一相位逻辑。

## 5. 验收

`npm run test:visual` 会在桌面和移动端执行以下检查：

1. Water 时间与泡沫 uniform 始终一致；
2. 调试状态中的相位误差小于 `0.006`；
3. `1.20` 快档在同一时长内至少比 `0.20` 慢档推进四倍；
4. 滑杆输出和恢复到 `0.55` 的状态正确；
5. 控制台、布局和既有场景回归无错误；
6. 保存 `desktop-wave-foam.png` 和 `mobile-wave-foam.png` 供人工检查。
