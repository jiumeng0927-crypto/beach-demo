# 潮汐沙岸：地表脚步声指南

## 1. 设计目标

脚步声是第一视角漫步的可选反馈，不改变场景模型、材质、镜头或玩法。设置默认关闭，页面
启动和普通浏览期间不会创建 `AudioContext`、音频缓冲或播放节点，也不会下载声音文件。

## 2. 延迟初始化

用户勾选“漫步脚步声”后，`FootstepAudio` 才在该点击手势内创建并恢复 Web Audio 上下文。
这符合浏览器的自动播放限制，也避免默认静音时占用声卡资源。关闭开关会把主增益立即设为零，
再次开启复用同一个上下文；页面销毁时再关闭上下文。

## 3. 位移节奏

系统在渲染循环中读取相机的实际水平位移，只在以下条件同时成立时累计步距：

- 相机处于 `walk` 模式；
- 漫步控制器确认镜头贴地；
- 用户已主动开启脚步声；
- 单帧位移小于瞬移保护阈值。

普通漫步每约 `1.05m` 触发一步，加速时使用 `1.30m` 步距。停止、离地、切换视角和较大位置
跳变都会清空未完成步距，避免站立、自由飞行或视角重置时误响。

## 4. 沙地与木栈道

`world.getWalkSurfaceType(x, z)` 复用木栈道已有的精确表面采样：采样命中木板时返回 `wood`，
其余可行走区域返回 `sand`。沙地脚步由衰减噪声和低通滤波合成，声音较松软；木板脚步使用
带通短噪声叠加低频三角波，形成更清晰的敲击感。两者均为一次性短节点，不使用外部音频资源。

## 5. 验收

`npm run test:audio` 使用假 Web Audio 上下文验证延迟初始化、步距、地表分流、瞬移保护、关闭
和销毁。`npm run test:visual` 在桌面和移动端点击真实开关，确认默认状态为 `not-created`、
开启后上下文运行、沙地与木板各触发一步，再关闭且不改变渲染统计。

脚步声只消耗触发瞬间的少量 CPU 音频节点，不增加 Draw Call、三角形、纹理、网络请求或运行时依赖。
