# 真实模型接入与沙滩布景

版本 0.35.0，2026-09-10。学习者：钱奕好。

## 本轮内容

保留海岸线、小船、躺椅、栈道、台球和原有视角，不加入人物。引入六类作者制作的 PBR 模型：野餐桌、木箱、塑料筐、救生圈、海螺、独立岩块。布置 16 个模型实例，原来 26 块程序岸石替换为同一真实岩块的轻量版本，保留 X/Z 分布、朝向和缩放，按新几何重新贴地。原独立救生圈位置使用真实模型，旧几何保留为加载失败时的后备。

另外用 Three.js 制作三把分片遮阳伞、三块冲浪板及支架、两张条纹沙滩巾。它们是本项目程序建模，不冒充网上下载的资源。桌椅、器材、自然细节各自成组，原来的台球区域与导入资源展示点保持空闲。

继续细化后，冲浪板拥有椭圆截面、翘头和尾鳍，中线贴合板面；伞面带垂边与连接环，支架带底脚和斜撑。细节保留在原批次中，底脚同步纳入漫步碰撞范围。

## 搜索与筛选

整体风格已按用户确认统一为柔和半写实海滨，扫描与程序材质的协调方法、共用色板、环境光和棕榈轮廓见 [画风规范](COASTAL_ART_DIRECTION.md)。

资源来自 Poly Haven 官方资产页面和公共 API，许可清单见 [第三方素材来源](THIRD_PARTY_COASTAL_ASSETS.md)。运行时只请求项目里的 GLB，不访问素材站。

第一次选中的 `coast_rocks_03` 是地表扫描片段，放到现有沙面上出现突兀裁边，近景验收后弃用。最终选择独立 `boulder_01`。这说明“下载成功”和“适合场景”是两件事，必须实际渲染检查。

## 文件流程

1. `npm run fetch:coastal` 从官方 API 读取 1K glTF 及依赖，下载到 `tmp/coastal-source`，逐文件检查大小与 MD5。已有且校验正确的文件复用。
2. `npm run prepare:coastal` 使用已安装的 Blender 导入 glTF、减面、缩小贴图并输出内嵌资源的 GLB。源下载文件不受修改。
3. `public/models/coastal/manifest.json` 记录作者、许可、原始下载链接与 MD5、输出面数、大小和 SHA256。六个最终 GLB 共约 2.43 MiB。
4. `npm run test:coastal` 校验哈希、模型加载、贴图、落地、反射、画质切换、资源释放及缺失文件降级，并生成桌面/手机各四张截图。

野餐桌贴图保留 1024，其余使用 512。岩块带两个网格：近景约 3500 三角形，原岸石使用约 480 三角形的 `CoastalShoreLOD`。LOD 是按用途选择，不是每帧按距离切换。

## 减面的真实问题

glTF 常因法线或 UV 接缝拆分位置相同的顶点。独立岩块首次减面没有达到目标，不能只相信 modifier.ratio。脚本先用 BMesh 合并重合位置，保留每个面的角点 UV，再应用 Decimate，并检查实际三角形数量。Blender 使用 `--python-exit-code 1`，避免 Python 脚本失败却被当成导出成功。

## 接入与所有权

`CoastalProps` 独立持有模型，不放进每次画质切换都会销毁的 world 根节点。GLTFLoader 解析内嵌 GLB；相同原型的多个位置用 InstancedMesh，共享材质和贴图。原型网格不参与渲染，但仍归系统持有并最终释放。

切换画质只重新绑定新 world 的碰撞登记与反射排除，不重新下载。近景干沙道具根节点跳过镜像；替换岸石放在另一个根节点，继续参加水面反射。阴影开关作用于两个根节点。

销毁时用 Set 去重 geometry、material、texture 与 ImageBitmap，分别 dispose/close 一次；加载中销毁会取消请求，解析完成太晚的资源也立即释放。资源请求设 15 秒上限，单个文件缺失不会阻止基础场景进入。

## 位置与碰撞

先读取可见原型的真实包围范围，不把备用 LOD 混入尺寸测量。归一化后施加旋转和缩放，再遍历真实顶点求最低点。旋转后的包围盒角点可能在实体下方，尤其是圈形物体，所以不能用它估算贴地高度。

大型桌子、箱筐、岩块与支架登记简化碰撞体；伞柱用圆形柱体。它们用于第一人称漫步，不是可推动的刚体。海螺、沙滩巾和救生圈保留为低矮装饰，不阻断通行。

## 成本与验收

本轮新增内容明显多于 0.34.0，因此明确分开约束：近景道具几何不超过 55000 三角形，26 块岸石合计不超过 13000；完整帧含阴影和镜像，桌面三角形上限 300000、手机 125000，绘制调用上限仍为 112/56。不能把几何数量误当成整帧绘制数量。

完整生产场景回归已通过：桌面 112 次绘制 / 290279 三角形，手机 49 次 / 123192 三角形；无控制台错误与布局溢出，资源释放通过。模型截图位于 `screenshots/coastal-*-*.png`。继续修改后需重跑 `npm run test:visual` 和 `npm run test:billiards-input`，确认夜景、天气、移动视角、导入功能和台球未回归。

练习：只调整 `COASTAL_PLACEMENTS` 中一个箱子的朝向，观察贴地与碰撞，再比较画质切换前后的下载次数。不要通过每次切换画质重新加载 GLB 来实现画质变化。
