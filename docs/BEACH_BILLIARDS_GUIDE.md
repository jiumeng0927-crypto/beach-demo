# 沙滩中八：规则、物理与交互学习指南

当前 0.43.0 的观察/击球状态、锁定拉杆相机及录音音效见 [状态与锁镜学习记录](BILLIARDS_INTERACTION_043.md)。以下保留 0.33.0 规则/物理基线；旧俯视拖拽击球已停用，两位游客已在后续版本接入。

对应版本：0.33.0，2026-09-09。同一设备上两人轮流操作的中式八球，现支持真实旋转参与走球与可调台呢；不包含电脑对手或联网对战。人物仍不加载，海岸布局保持原样。

## 1. 规则依据与实现范围

采用中国台球协会公开的[《中式台球竞赛总则（2017 年 1 月修订）》](https://cbsa.cssf.net.cn/annoucement/2017/0120/142126.html)作为明确的规则基线，不宣称它是最新赛事规则。该版本无需指球定袋，勿与要求黑八报袋的其他规则混用。

| 项目 | 本项目处理 |
| --- | --- |
| 球与球台 | 1 颗母球、15 颗编号球；内沿长宽比例 2540:1270，球径按 57.15 mm 同比例缩放 |
| 摆球 | 五行三角形，黑八居中，底边两角分别是全色和花色 |
| 球组 | 开球不分组；之后依据合法首碰及入袋球确定全色/花色归属 |
| 开放球局 | 可首碰全色或花色，不能首碰黑八；只打进另一组不确定球组并换手 |
| 出杆与换手 | 合法打进本组继续，合法空杆换手；首碰错误、未碰球、无进球且未碰库、母球落袋或球出台判犯规 |
| 自由球 | 普通犯规为全台自由球；相应开球犯规为线后自由球 |
| 非法开球 | 未进球且不足四颗目标球碰库，对方可接受台面、自己重开或要求对手重开；受警告后再次不足四球判负 |
| 开球进黑八 | 复位黑八，不直接获胜；伴随犯规时按规则提供台面/线后选择 |
| 黑八结算 | 本组在之前一杆已清空才能合法打黑八；提前进八、同杆清最后一球与黑八、进八同时犯规均判负 |

这是教学用规则模拟，不是赛事认证模拟器。支持高杆跟进、低杆拉回、左右加塞、球间及库边切向摩擦。暂不模拟跳球、弧线球、抬杆、杆头二次触球、比球、裁判计时或人为行为处罚。第一局固定 P1 开球；重置是新局。平移限制在台面，三个轴的旋转参与动力学，不再使用位移伪造滚动。

## 2. 操作

1. 点击台球面板定位按钮，回到环绕视角。
2. 按住母球向后拖拽，松手出杆。轻点不出杆；拖动至少 6px，力度至少 0.06。
3. 球静止后面板显示当前玩家、球组、剩余球和判罚。
4. 自由球时点击台面放置母球，然后点击“确认落点”。也可再次选择“摆放母球”调整。
5. 开球与线后自由球需把母球置于开球线后并向顶库方向击打；重叠、袋内、台外、越线位置会被拒绝。
6. 全部合法目标都在线后时，程序自动把最接近开球线的合法目标复位到置球点。等距时自动选编号较小者。
7. 点击台球 HUD 的滑杆图标打开“杆法与台呢”：纵向调整高低杆，横向调整左右塞，可组合；十字图标恢复中杆。球形图显示实际杆头偏移。
8. 滑动摩擦默认 0.200，滚动摩擦默认 0.010。降低滚动摩擦使台面更快；回转箭头恢复台呢默认值。球运动期间禁止修改，关闭面板后按原方式击球。

鼠标与触摸共用 Pointer Events。为便于手机操作，按标准比例缩小后的母球保留 14px 屏幕命中半径。拖动期间暂停 OrbitControls；取消触摸、失去捕获、窗口失焦、隐藏页面、WebGL 上下文丢失或镜头切换会取消出杆。

## 3. 源码分工

| 文件 | 职责 |

| `src/experience/ChineseEightBallRules.js` | 纯规则状态，不依赖 DOM、Three.js 或物理引擎 |

| `src/experience/BeachExperience.js` | 镜头、事件转发、懒加载、反射排除和启停 |

数据流：拖拽 -> `shoot` 创建一杆记录 -> cannon-es 碰撞 -> 累计首碰/碰库/落袋 -> 静止后 `finishShot` -> `rules.settle` -> HUD。不要在每颗球入袋时立即判胜负，否则最后一颗本组球与黑八同杆入袋会被错误判胜。

## 4. 尺寸与固定步进

采用 2.5 场景单位/米，内沿为 6.35 × 3.175，球半径为 0.0714375，库顶高度为 2.01，对应约 0.804 米。球桌外观为沙滩木框风格，不复制某品牌球台。

物理仍使用 `cannon-es 0.20.0` 的碰撞检测和 Gauss-Seidel 求解器。零重力、X/Z 位移约束、三轴自由旋转、SAP 宽相位、24 次求解迭代。滑动和滚动以接触点冲量/阻力处理，静态库边在最终位置创建并更新 AABB。球速上限 9，每步 1/240 秒，最大步进位移 0.0375，小于半径。

袋口采用教学紧口配置：角袋最窄胶边间距 85mm，中袋 100mm，袋角半径 10mm。不是已认证的星牌或乔氏某型号尺寸；原规则页面没有给出这些袋口数值。收到指定型号规格后，应整体调整袋角、袋唇和袋口深度，而非只改黑圈。详见 [物理推导与限制](BILLIARDS_PHYSICS_GUIDE.md)。

```js
accumulator += Math.min(delta, 12 / 240);
while (accumulator >= 1 / 240 && steps < 12) {
  world.step(1 / 240);
  // 在两个引擎 step 之间检查袋口并移除入袋刚体。
  accumulator -= 1 / 240;
}
```

球中心必须越过袋口喉线，进入后方凹陷袋体的有效区域才落袋；沿上一位置到当前位置的线段检查同一条件，擦过台面边缘不会被直接吸走。这不是球与球之间的连续碰撞检测。不能给 cannon-es 添加其源码未使用的 `ccdSpeedThreshold` 等属性并声称开启了 CCD。

不在引擎 `postStep` 回调内移除刚体：其内部后续循环可能仍使用步进前的刚体数量。在外部固定步进循环间移除，可以避免数组长度变更导致的问题。

## 5. 接触与结算

- 一杆记录开始时缓存已有接触，避免把原本贴库算作新碰库。
- 第一次母球与目标球接触时记录编号；同一步同时接触合法与非法目标时优先合法目标。
- 碰库按球编号去重，以支持四颗不同目标球碰库的开球判断。
- 普通击球只接受首碰后的新碰库；只有碰库没有碰目标球仍是犯规。
- 一杆完全停止后统一更新球组、玩家、犯规、自由球和胜负。
- 开球黑八复位时优先沿置球点向顶库寻找不重叠位置，必要时向反方向寻找。

## 6. 渲染与资源

16 颗球仍是一个 `InstancedMesh`。每实例带编号属性，从 4×4 图集中取对应区域。花色球带白色两端和彩色中带，所有目标球有两面数字。可见四元数来自真实刚体旋转。片元 Shader 先将插值编号四舍五入，避免 4、8、12 号因浮点误差跨格采样而出现杂色。

球桌、球框、袋口、球体共 4 个常驻绘制对象，瞄准线出现时为 5 个。增强模型只增加几何数量，不按每颗球新增绘制调用。球移动后刷新实例包围球，保证新的位置仍可被射线命中。

进入场景后才加载物理模块与创建台球资源。关闭复用资源；销毁时释放 5 组几何/材质与 2 张程序纹理，共 12 个被测试的资源。

```bash

```

- 规则测试覆盖合法/非法开球、球组、组合球、换手、首碰、自由球、黑八与重开选择。
- 物理测试用 20/30/60/120/240fps 对六个袋口逐一击球；新增 60 次库边反弹（中等力度及满力）、60 次袋角拒球、袋口最窄宽度、高低杆、左右塞、摩擦距离和参数锁定测试。
- 浏览器使用真实鼠标和触摸检查轻点、拉杆、取消、镜头互斥、后续出杆、母球落袋及自由球确认。
- 整站回归继续覆盖天气、潮汐、探索、视角、导入、画质与资源释放。纯画布像素对比临时隐藏 HUD，防止把面板遮挡当作 3D 效果缺失。
