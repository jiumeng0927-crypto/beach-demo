# 中八物理修复与杆法学习

版本 0.33.0，2026-09-09。作者/组员：钱奕好。项目：潮汐沙岸。

## 1. 为什么原来的库边会漏球

Cannon 的 `Body` 构造器在添加形状后计算质量属性，同时生成 AABB。旧代码先在原点创建 Box，再设置 `body.position`，却没有使 AABB 失效。实际库边已在桌边，SAP 使用的包围盒仍在原点，因此并非只有看起来缺失的一段存在风险。

修复方式：构造器传最终 `position`，添加所有袋角形状之后调用 `updateAABB()`。摆球、重开、复位移动动态刚体时设置 `aabbNeedsUpdate = true`。测试不仅检查包围盒包含真实中心，还在五种帧率下逐段击球。

## 2. 尺寸统一

每米使用 2.5 场景单位；台面内沿 2540 × 1270mm，球径 57.15mm，球质量 0.17kg。规则尺寸来源是中国台球协会的[2017 年规则基线](https://cbsa.cssf.net.cn/annoucement/2017/0120/142126.html)。

角袋 85mm、中袋 100mm 是本次选用的教学紧口配置，测量位置为两侧胶边最窄处，并非从上述规则推导出的统一认证袋口。厂家、赛事和测量位置会产生差异。关于袋口还要共同检查袋角、袋唇、深度及鼻口的原因，可参阅[制造商规格说明](https://sundaysbilliard.com/blog/chinese-8-ball-pocket-size-specification-guide)。

`billiardsTable.js` 统一生成：

- 六段库边，每段包含主体 Box 和两个圆弧袋角 Cylinder，仍只有六个静态刚体。
- 袋角弧面半径 10mm。角袋两袋角中心距离减去两倍半径等于最窄袋口宽度。
- 台面通过 Shape 的 holes 实际开孔，袋内壁、袋底、袋唇组成同一个可实例化几何。
- 落袋要求球心越过喉线 0.045 场景单位，并进入后方落袋区域；袋口没有吸引力。

这是刚性圆弧袋角近似，不是完整橡胶形变或真实袋网弹性模型。落袋后移除刚体，没有模拟球在袋网里继续弹跳。

## 3. 杆头偏移与惯量

实心球转动惯量 `I = 2/5 * m * R²`。Cannon 默认质量更新使用包围盒惯量近似，因此此处对单球明确设置球体惯量，而不是直接依赖默认值。

母球出杆平移速度是 `9 * power^1.5`，最小力度 0.06 约为 0.132 场景单位/秒，保留轻推球；最大力度对应 3.6m/s。冲量等于速度乘质量。

以单位击球方向 `(dx, 0, dz)` 为例，杆头接触偏移为：

```js
offset = (-dz * tipX * 0.7 * R, tipY * 0.7 * R, dx * tipX * 0.7 * R);
body.applyImpulse(impulse, offset);
```

`tipX/tipY` 限制在单位圆内，总偏移不超过 0.7R。高杆产生向前滚动趋势；低杆反向旋转，撞目标球丢失平移速度后，台呢摩擦使母球拉回。左右塞产生竖轴旋转，接触库边后通过切向摩擦改变反弹角度。显示的旋转来自物理四元数，不是额外动画。

本版不模拟跳球、弧线球、偏移击球的杆头弹性/squirt、失误滑杆或抬杆。高低杆效果取决于球距、力度和台呢，远距离低杆可能在撞球前已衰减为滚动，不能保证每次选择“低杆”都拉回。

## 4. 台呢摩擦

底部接触点为 `(0, -R, 0)`。台面上的滑移速度为：

```js
slipX = velocity.x + R * angularVelocity.z;
slipZ = velocity.z - R * angularVelocity.x;
```

滑动时在底部施加反向冲量，大小取 `muSliding * m * g * dt` 与 `2/7 * m * slipSpeed` 的较小者，避免单步跨过无滑动状态。`2/7` 来自实心球平移和转动共同改变接触点速度。滑移消失后使用恒定滚动阻力，并满足无滑动约束。竖轴旋转另按有限接触斑模型衰减。

默认滑动系数 0.200、滚动系数 0.010、球间摩擦 0.05、球间恢复系数 0.95、库边摩擦 0.20、恢复系数 0.85。参数参考开源 [pooltool BallParams](https://pooltool.readthedocs.io/en/v0.4.4/autoapi/pooltool/objects/index.html)；滑动、滚动、旋转的区分参考其作者的[物理推导](https://ekiefl.github.io/2020/04/24/pooltool-theory/)。它们是教学模拟初值，不是本地某张实体台呢的实测校准结果。

无重力世界中，Cannon 原有的 `friction * gravity` 上限为零，简单填写 friction 并不能产生加塞效果。本版使用 `frictionGravity` 建立摩擦方程，再按碰撞法向冲量设置 Coulomb 上限，仍由 Cannon 的 GS 求解器处理切向速度与旋转。注意其实现直接限制 lambda 冲量，不能再除以 dt 当作力传入，否则摩擦会过大。

滑动系数可调 0.12–0.30；滚动系数可调 0.006–0.020。球在运动时锁定参数，避免在同一杆中改变台速。三个旋转轴允许运动，垂直平移仍受约束，因此没有真实跳球。

## 5. 回归证据与练习

运行 `npm run test:billiards`，包含原有 18 项规则、30 次有效落袋、60 次库边反弹、60 次袋角拒球和旋转/摩擦检查。库边、袋角和入袋测试遍历 20、30、60、120、240fps。

固定测试条件下：低杆击中目标后的母球 x 速度约 -0.529，高杆约 +0.703；左右加塞碰库后 x 速度约 +0.486 / -0.486，中杆接近 0。初速 1 且已经纯滚动的母球在两秒内，系数 0.006 走约 1.705，系数 0.020 走约 1.017。单位均为场景单位。

练习：只改滚动摩擦，记录同初速停止距离；只改杆头高度，比较近距离和远距离低杆；向每个袋角偏离袋口中心射球，确认打库后弹回而不是被吸入。之后执行 `npm run test:billiards-input` 和 `npm run test:visual`，检查真实输入、近景球号、画布像素、移动端和资源释放。
