# 柔和半写实海滨：统一画风

初版 0.35.0，2026-09-10。学习者：钱奕好。

0.36.0 补充：最新目标允许加入 NPC，使用两位穿日常服装的授权游客模型；原 Q 版素材不启用。下面“不加入人物”描述的是 0.35.0 当时范围。水面与人物接入规范见 [水体与 NPC 学习记录](OCEAN_AND_NPC_GUIDE.md)，保留原场景布局和半写实海滨基调。

## 目标

用户确认采用“柔和半写实海滨”。保留海岸、船、躺椅、栈道、台球的位置与玩法，不加入人物。扫描模型与程序建模共用柔和光照和适度风化的材质，避免一部分像塑料玩具、另一部分像重度破旧的道具。

这不是全场景重新拓扑或照片级重建。棕榈、船、冲浪板仍为轻量程序网格，扫描模型仍经过减面，近看会保留几何简化痕迹。

## 共用配色

`src/experience/CoastalStyle.js` 保存 `COASTAL_PALETTE`，原场景和新增器材从这里读取。以后增加道具应优先复用它，而不是各自选一套饱和色。

| 用途 | 色值 | 对象 |
| --- | --- | --- |
| 柔白 | `#e5e7df` | 伞面、遮阳棚、条纹 |
| 灰珊瑚色 | `#ad7066` | 躺椅布、伞面、毛巾、冲浪板、船用救生圈 |
| 海玻璃蓝绿 | `#588f91` | 木船漆面、冲浪板、遮阳伞、毛巾 |
| 鼠尾草绿 | `#718674` | 伞面点缀，与植被协调 |
| 低饱和赭黄 | `#b6a173` | 冲浪板点缀 |
| 风化木 / 暗木 | `#968672` / `#6d6052` | 船沿、栈道、器材支架 |

## 材质方法

- 布料：粗糙度约 0.92-1，降低躺椅的丝绒亮边；伞、巾、椅、棚使用同一微弱织纹。`fwidth` 在远处淡出细纹，减少摩尔纹。
- 漆面：冲浪板粗糙度调为 0.48；船身保留小划痕，缩小掉漆斑块，降低清漆层。
- 木材：原船沿和栈道共用风化木色，减弱程序木纹的粗条带反差，保留结构阴影。
- 扫描资产：保留原始颜色、法线、粗糙度和金属度贴图。颜色采样后饱和度降到原来的 80%，轻微抬起暗色；法线强度设为原来的 60%，岩块保留 78%，AO 强度为 0.65。
- 修改只作用于本项目内置六类资源，不会改写用户后来导入的模型，也不会重写原始 GLB 或源贴图。

`addCoastalSurfaceDetail` 和 `styleCoastalAsset` 使用 `onBeforeCompile`，保持 Three.js 原有灯光、阴影、反射和色彩空间流程。不是屏幕滤镜，不用自发光提亮道具，不新增纹理或逐帧材质分配。共享材质去重后只处理一次，切换画质不会反复削弱法线。

## 环境与轮廓

日光采用中性暖白直射光和较柔的环境补光。海水减少无色漫反射，增强蓝绿水体与远海蓝色；沙滩维持低饱和暖灰。Sky 的同一日间蓝色校正同时作用于可见天空和 PMREM 环境源，夜间权重归零，阴天降低可见天空的校正权重，没有固定蓝色滤镜覆盖所有时段。

棕榈叶改为先拱起再下垂的弧线，叶轴由 13 段改为 21 段，配合低饱和的根端绿色。保持原有五棵树的根部位置与海风动画，不增加独立绘制对象。

## 后续器材细化

继续优化时，将冲浪板的平面挤出改成 `LatheGeometry` 生成的连续椭圆截面，缩小厚度方向后加上纵向翘曲，并重新计算法线。单块主体从 428 降到 360 三角形，同时具有圆润板边、弧面厚度和翘头。白色中线复用同一剖面采样点，避免装饰浮在弧面之外；尾鳍放在背面。

遮阳伞使用原外圈顶点延伸垂边，并补充伞柱连接环；冲浪板架增加底脚与斜撑，同步扩大漫步碰撞范围覆盖底脚。主体、装饰、尾鳍仍合并进原来的板组，伞边仍合并进伞面，维持 12 个近景道具绘制批次。

## 验收与练习

1. `npm run test:coastal`：验证六类资源、统一材质类型、船椅配色、天空校正、贴地、画质复用和销毁。查看 `screenshots/coastal-*.png`。
2. `npm run test:models`：查看旧船、躺椅、棚和栈道近景，确认主地标坐标不变。
3. `npm run test:visual`：覆盖桌面与手机、昼夜、天气、阴影、导入、雨幕和完整帧预算。
4. `npm run test:billiards-input`：检查鼠标和触摸出杆。画风修改不能改变碰撞、杆法和规则。

完整帧预算仍为桌面 112 次绘制 / 300000 三角形，手机 56 次 / 125000。测试检查实际编译与画面非空，审美统一仍需人工查看截图，不能把断言通过当作“完全写实”。

最终生产构建（含器材细化）完整场景回归通过：桌面 112 次 / 290279 三角形，手机 49 次 / 123192 三角形；无控制台错误或布局溢出，销毁检查通过。18 项中八规则、60 次库边反弹、60 次袋角测试、30 次进袋及高低杆/左右塞/摩擦测试通过。

练习：只修改 `COASTAL_PALETTE.coral`，比较船圈、躺椅、伞和巾是否同步；在四个时段比较，避免只为一个时间段调色。
