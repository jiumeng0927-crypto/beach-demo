# 潮汐沙岸：构图书签指南

## 1. 设计目标

构图书签用于课程展示和场景讲解时快速返回观察点。设置面板提供 3 个独立槽位，每个槽位只
记录透视相机位置与 `OrbitControls.target`，不记录或修改时段、天气、潮位、雨幕、画质、玩法
进度、导入资源和场景内容。

## 2. 数据边界

`CameraBookmarks` 不直接控制 Three.js 相机，只负责验证、复制和持久化构图数据：

- 槽位仅允许 `1-3`；
- position 与 target 必须各含 3 个有限数值；
- 坐标绝对值不能超过 1000，损坏或篡改数据不会进入相机；
- 对外读写均复制数组，调用方不能意外修改内部状态；
- localStorage 不可用时仍可在本次页面中使用内存书签。

数据保存在 `tideline.camera-bookmarks.v1`，包含格式版本、槽位号、相机位置、观察目标和保存时间。

## 3. 保存与恢复

环绕视角直接保存当前 camera position 与 controls target。漫步或自由视角保存时，以当前朝向
前方 14 米生成观察目标，并限制在已有 Orbit 目标边界内。

点击“前往”后，应用会先退出指针锁定模式，再复用重置镜头已有的 1.15 秒三次缓入缓出插值，
同时插值相机位置和观察目标。恢复开始时设置面板自动收起，便于直接观看构图；开启系统减少
动态效果时，过渡缩短为近乎即时。

## 4. 独立性与成本

书签不加入场景对象、几何体、材质、纹理或渲染通道。保存与删除只在用户点击时写入少量 JSON，
恢复期间复用已有每帧相机缓动，因此 Draw Call、三角形和 GPU 帧预算保持不变。

## 5. 自动验收

`npm run test:bookmarks` 验证槽位、覆盖、复制、持久化重载、删除、损坏数据和写入失败兜底。
`npm run test:visual` 在桌面与移动端执行“空槽位、保存、移开、恢复、切换空槽、删除”完整流程，
并比较恢复前后的镜头、环境状态、渲染统计、按钮状态、localStorage 与界面溢出。
