# 潮汐沙岸：清晨薄雾预设指南

## 1. 设计目标

清晨不是给场景叠一层半透明灰色，而是沿用现有时间系统同时改变天空散射、光照、雾、
水面和地表色彩。它是可选的第四个时段，默认仍为日光，因此不会改变项目原有首次画面。

## 2. 统一预设

`environment.js` 的 `PRESETS.dawn` 与日光、黄昏、月夜拥有完全相同的数据结构：

- `elevation=7.5` 与暖色主光形成低角度晨光；
- 较高 turbidity、Mie 系数和 `FogExp2` 密度柔化远景；
- 冷灰雾色与暖色太阳分离前后景色温；
- Water 地平线色、深水色、反射和高光同步变化；
- 云层亮部/阴影、干湿沙、泡沫与 daylight 一起过渡。

全部数值继续通过原有指数平滑链更新，不创建新的灯光、雾对象、材质或渲染通道。

## 3. 为什么使用 FogExp2

Three.js `FogExp2` 在近处保持相对清晰，并随距离加速增密，适合让主船和操作路线可读，
同时弱化海平线。清晨密度为 `0.0034`，约为默认日光的 3.1 倍；晴朗、多云和阴天仍可用
各自的 `fogScale` 继续叠加，不需要复制天气逻辑。

## 4. 状态独立性

选择清晨只修改时间目标状态：

- 不切换天气或雨幕；
- 不改变潮位与海浪速度；
- 不重置玩法、镜头或导入资源；
- 不增加 Draw Call 或三角形；
- 切回日光会恢复原有参数。

## 5. 自动验收

`npm run test:visual` 在桌面和移动端点击真实“清晨”按钮，保存 `desktop-dawn.png` 与
`mobile-dawn.png`，并检查时间标签、激活按钮、雾密度、太阳强度、云量、月光、水面色、
布局溢出和渲染统计。截图仍需人工查看主体是否清楚、薄雾是否自然以及控件是否遮挡画面。
